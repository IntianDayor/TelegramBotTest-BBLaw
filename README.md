# TelegramBotTest-BBLaw

This project is a **test web application integrated with a Telegram bot** created using BotFather. It was built as an experimental setup to test bot interactions, command handling, and basic web-based RNG (random number generator) functionality.

---

## 🚀 Overview

This project demonstrates a simple Telegram bot workflow where users can interact with a bot and trigger a web-based feature.

The bot is accessible on Telegram under:

👉 **@bosebose_bot**

---

## 🎮 How It Works

1. Open Telegram and search for **@bosebose_bot**
2. Press **Start**
3. Click the **Open RNG** button
4. The bot will interact with the web app and return a random number result
